# MacKey

一个面向中文用户的 macOS 交互式学习网站，帮助从 Windows 迁移到 Mac 的用户，用“直接上手”的方式熟悉键盘、触控板和常见操作逻辑。

它不是一份静态说明书，而是一套更接近真实使用场景的练习体验：看到提示，按下按键，立刻得到反馈。

## 我们想解决什么问题

很多刚开始使用 Mac 的用户，不是不知道“有快捷键”，而是不知道：

- 哪些键在 Mac 上分别是什么意思
- Windows 里的习惯，在 Mac 上应该怎么做
- 快捷键背下来之后，实际场景里该怎么用
- 触控板手势到底值不值得学，应该从哪里开始

MacKey 的目标，就是把这些学习成本拆开，让用户在真实操作反馈里建立肌肉记忆，而不是靠死记硬背。

## 网站内容

- **交互式课程**：3 门课程、13 个章节、24 节内容，从入门到进阶逐步学习
- **快捷键参考手册**：67 个常用快捷键，覆盖 8 个分类，支持浏览与检索
- **虚拟键盘练习**：按下真实键盘时，页面会同步高亮对应键位
- **场景化学习**：把复制、切换应用、截图、Spotlight 等操作放进真实语境里练
- **触控板手势库**：15 个常见手势，带动作说明和使用场景
- **Mac / Windows 对照**：帮助用户把旧习惯映射到新的键位逻辑

## 适合谁

- 刚从 Windows 切换到 Mac 的中文用户
- 想系统补上 macOS 基础操作的人
- 记不住快捷键，但愿意边做边学的人
- 想把触控板和键盘效率真正用起来的人

## 网站结构

- `/`：首页，介绍学习方式和核心入口
- `/courses`：课程总览与逐课学习
- `/reference`：快捷键手册
- `/practice`：自由键盘练习
- `/practice/keyboard`：课程式键盘练习
- `/gestures`：触控板手势
- `/compare`：Mac 与 Windows 键位对照

## 产品特点

### 1. 先反馈，再记忆

用户不是先看长文说明，而是先看到动作提示和结果反馈，再慢慢形成对快捷键的理解。

### 2. 学习路径清晰

从认识修饰键，到最常用快捷键，再到截图、窗口管理和手势，内容是递进设计的。

### 3. 更适合中文语境

整个站点围绕中文用户的学习习惯设计，尤其照顾从 Windows 切换到 Mac 的过渡体验。

### 4. 不是“查资料”，而是“练会”

参考手册负责查询，课程和练习负责把动作练熟，两者分工明确。

## 本地开发

在项目根目录运行：

```bash
npm install
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000) 查看。

## 生产构建

```bash
npm run build
npm start
```

## 项目定位

MacKey 更像一个 macOS 学习产品原型，而不只是一个内容站。它关注的重点是：

- 信息是否容易理解
- 动作是否有清晰反馈
- 学习路径是否足够自然
- 初学者是否真的能在几分钟内开始上手
